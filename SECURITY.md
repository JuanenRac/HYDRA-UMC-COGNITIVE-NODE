## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In a cognitive robotic system, a reasoning flaw can lead to unpredictable behavior. If you discover a vulnerability affecting the **LLM prompt injection**, **VLA action integrity**, or **offline boundary bypasses**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows bypassing ethical/safety constraints, leaking system state, or hijacking the mission planner.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
